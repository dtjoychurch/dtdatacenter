**鑰節:「大衛甚是焦急，......大衛卻在耶和華他的神裡勉勵自己。」 ( 撒上 30:6)**

( 編者按:這是 King James 版本的翻譯，而和合本中文聖經為:「......大衛卻倚靠耶和華祂的神， 心裡堅固。」)

這課以撒上 30:1-6 為基礎，我們會思想大衛人生中一段陷入極度痛苦與患難的時期，以及看看在 患難的時刻他作了些甚麼，並主如何奇妙地為他承受這一切患難。患難對所有人都是一視同仁的 ( 約 5:7; 14:1)。也許你現在正經歷患難的時刻吧?若然，這一課會對你有幫助;而若然今日你不 是在患難中，這課題會預先讓你為將來有朝一日作好準備，因為患難會臨到我們所有人，若我們 知道在患難時該作甚麼是一件好事。注意，從撒上 30:1-6，我們看到:

**一、大衛的患難是非常真實的**

從這些經文得知，它完全不是虛構出來的。與他的患難相比，你的又如何呢?你的患難是否 與你人生中某些極大的損失有關? (30:1);它是否與你所愛的有關連 (30:3) ?它是否大到使 你哭，直哭得沒有氣力 (30:4) ?我們的患難是多麼真實啊!它們完全不是虛構出來的，而且 哭並沒有錯，當我們受不了時用這種方法來減輕痛苦也是沒錯的 ( 約 11:35)。

**二、 大衛雖是神的兒子他仍會遭遇患難**

注意這點是很重要的。主愛大衛 ( 查閱徒 13:22);但大衛仍會身處這些痛苦非常的境況中。 我們基督徒千萬不要期望對患難會有免疫力。想想主受了多少苦 ( 來 13:12)，以及使徒保羅 忍受了多少苦楚 ( 林後 11:23-30) !真的，你能否想到有一位真正是神兒女的未嘗試煉與考 驗的苦楚?在我們的生命路上遭遇患難，不要以為神不愛我們 ( 查閱彼前 4:12)。

**三、 主容許大衛的患難**

祂准許患難發生。祂准許痛苦臨到祂兒女的生命，正如祂對約瑟 ( 創 39:20)、耶利米 ( 耶 37:15)、彼得 ( 徒 12:5-6) 以及本仁約翰 (John Bunyan) 一樣，神今日對祂許多的僕人也一 樣。當約伯被痛苦擊打時，他對主的信心是多麼堅定，亦由於神是至高者，沒有任何事情會 在人生中發生，或將會發生而沒有經神的恩准，所以他能說 ( 伯 13:15)。主能阻止約伯的患 難出現，祂也能阻止我們所有的患難出現;但祂並不這樣做，祂希望我們學習的最大功課， 是當祂這樣對待我們，在我們不能明白許多的「為甚麼」的時候信靠祂。羅 8:28 是真實的， 它永遠也是真實的。

**四、 按真實的意義來說，大衛的患難是出於他自己的過錯。**

這是很嚴重的事，因為大衛曾犯罪跌倒，沒有神的兒女這樣做而能逃避神的管教。很明顯， 主容許患難臨到大衛的生命，致使他能悔改 ( 查閱詩 55:19，及比較申 8:2-3 節及來 12:6)。 掃羅的故事同樣記載於同一卷書上，他如大衛所作的，無視神的權柄，「但在這兩個個案中 我們可見審判與管教之別。在掃羅的例子中，他的性命和事業被終止，作為他犯罪的懲罰; 然而，在大衛的例子中，所舉的杖是用來管教──不是毀滅;是領他回轉，不是把他趕盡殺 絕;是使他成為合用的器皿，不是將他拆毀。」也許你的患難是來自你自己的過錯，( 查閱 創 42:21，並注意「所以」這個詞 )。但神亦會為著自己的榮耀和我們的益處而將懲罰成為管 教，在我們生命中考驗和試煉中成就祂的義。

**五、 大衛的患難其實是一個化妝的祝福。**

你說:「這怎麼可以?妻子、居所和朋友都失去了?」這是一個化妝的祝福因為第 8 節告訴 我們大衛求問耶和華;而任何驅使我們到主那裡的經歷都是有價值的 ( 查閱詩 119:67 及來 12:11)。神正在你和我的生命中尋找一樣東西，那就是完全順服於祂。祂盼望我們愛祂和祂 的旨意，並完全信靠祂。當大衛在患難之時他作了些甚麼?第 6 節告訴我們他「在耶和華他 的神裡勉勵 ( 或堅固 ) 自己。」勉勵他人是好的，但有時我們也需要在主裡勉勵自己。我們 怎樣可以做得到?

1. 提醒自己你屬於祂。「大衛在耶和華他的神裡勉勵自己。」要在這個關係的保證中得著 安息。

2. 回想祂過去的憐憫。過去祂如何奇妙地為你承擔，帶領你，祝福你，供應你和使用你 ( 撒 上 7:12)，今日祂也不會改變。

3. 轉向祂。透過認罪 ( 約壹 1:9)、祈求 ( 詩 34:6)，在祂面前謙卑，單單仰望祂的拯救 ( 詩 69:17)。

4. 求問祂 (8 節 )。求問祂你在受考驗的處境中應作甚麼。

5. 聽從祂 (9 節 )。注意這節經文是怎樣開始的──「於是大衛......來到......」

6. 信靠祂。在第 8 節末神應許大衛獲全勝，當他去時 (9 節 )，他信靠主成就祂的話。所有 神給我們的應許都是為了要使我們完全信靠祂和祂的話，並信靠祂會在我們生命中為我 們實現祂所應許的 ( 查閱詩 37:5, 箴 3:5-6, 太 11:28, 羅 8:28, 腓 4:19)。

7. 感謝祂的良善 (23 節 )。( 查閱詩 9:9, 27:5, 46:1, 143:11;鴻 1:7)。

「耶和華本為善，在患難的日子為人的保障，並且認得那些投靠祂的人。」
