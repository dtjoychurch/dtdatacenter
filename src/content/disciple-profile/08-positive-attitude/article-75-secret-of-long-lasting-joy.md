**鑰節:「是要叫我的喜樂，存在你們心裡，並叫你們的喜樂可以滿足。」(約 15:11)**

上述是主耶穌所說的話，我們要特別留神。耶穌是在一個不尋常的時刻談論喜樂與愉悅，因為不 一會他將在黑暗的客西馬尼園中，隨後很快他便要面對他的控告者，並聽見那些恨祂的人發出的 辱罵與嘲弄。是的，正好在祂面對加略山的極度痛苦之前，祂說:「我的喜樂」;而且，極其重 要的，是在聖經的記載中，這是唯一一次祂談及祂的喜樂。若祂在如此大的試煉及考驗的時刻， 祂裡面仍存著喜樂，祂的喜樂必然是十分獨特的!──祂所渴望和賜給我們的 ( 即是給每一位信 徒 )，是祂的喜樂 ( 這與世界的喜樂迥然不同 ) 應該成為我們的喜樂。「是要叫我的喜樂，存在你 們心裡，並叫你們的喜樂可以滿足。」

**一、 基督徒的喜樂是生命的特徵**

太多時候，我們悲傷、憂鬱和沮喪;但作為基督徒我們應該凡事喜樂 ( 查閱腓 4:4 及帖前 5:16)。基督徒的經歷由始至終都應該有喜樂的標記:在悔改歸主時喜樂 ( 路 19:6; 徒 8:39); 在閱讀神的話語時喜樂 ( 耶 15:16);禱告中喜樂 ( 約 16:24);在試煉中喜樂 ( 雅 1:2);受苦 時喜樂 ( 徒 5:41);事奉時喜樂 ( 林後 1:24);在人生旅程終結時喜樂 ( 徒 20:24)。若我們愛 主和屬於主，我們應該常常喜樂。

**二、 甚麼是基督徒應經歷的喜樂?**

1. **它是基督的喜樂**:「是要叫我的喜樂，存在你們心裡」( 約 15:11)。「我的喜樂......在 你們心裡......」基督徒的生命是主耶穌基督的生命活在一個人裡面 ( 查閱加 2:20 及西 3:4)。基督徒的喜樂是基督的喜樂在一個基督徒裡面，意思是說，這種深度而恆久的喜 樂無法在任何地方找到，只有在祂那裡才能找到。在其他地方可以找到別種的喜樂，但 這種喜樂唯獨在祂那裡才找得到。

2. 它是滿足的喜樂 :「......叫你們的喜樂可以滿足」( 約 15:11) 。喜樂與滿足的喜樂有天 壤之別。一個器皿可以被充滿一部份或全然被充滿。我們的主期望我們經驗滿足的喜樂 ( 查閱詩 16:11, 約 17:13 及彼前 1:8)。

3. 它是恆久的喜樂:「是要叫我的喜樂，存在你們心裡」( 約 15:11)。「存在」這個詞表 示基督徒的喜樂不是一種間斷的經驗，而是永久性的經驗。它是一種不受環境影響的喜樂 ( 查閱主在約翰 16:22 對祂門徒所說的話 )。這些最早跟從主的信徒須經歷許多試煉 與考驗，但祂告訴他們沒有東西能奪去他們的喜樂──存在他們心裡的祂的喜樂。下列 三段經文描述基督徒喜樂的恆久性，及基督在我們裡面的喜樂不受外在環境及情況影響的事實，請加細想:

i. 約 15:11:如我們所見，我們的主在十架的陰影下經歷這種喜樂。
ii. 路 10:20:可以肯定，我們的主的意思是:「不要靠賴任何屬地或短暫的事物而喜樂， 唯獨靠賴天上的事物而喜樂。」
iii. 徒 16:25:保羅與西拉縱然在大患難中，仍充滿基督自己的喜樂，致使他們能在半 夜唱詩讚美 ( 比較賽 61:3, 林後 8:2 及來 10:34)。

真正的基督徒喜樂非但不為逆境所影響，反確實因上述的試煉與考驗而增加，這真是一件既 超凡又奇妙的事情 ( 查閱雅 1:2)。

**三、 我們如何能擁有這種喜樂?**

1. **藉著擁有基督**。倘若這種深沉、恆久的喜樂是基督的喜樂，那麼我們只能藉著擁有基督 而擁有它。在徒 8:8，我們唸到:「在那城裡，就大有歡喜。」為何會這樣呢?第 5 節 告訴我們!在徒 8:39，我們唸到太監「歡歡喜喜的走路。」為何會這樣呢?第 35 節告 訴我們!若我們要擁有祂的喜樂，我們必須擁有祂 ( 查閱約 17:13)。

2.** 藉著閱讀祂的話語**。當我們閱讀聖經並接受真理，我們會經歷大喜樂 ( 查閱約壹 1:4)。 這情況類似當主與我們說話，我們與主相交時產生一顆「火熱的心」( 查閱路 24:32)。

3. **藉著順服祂**。注意路 10:21 告訴我們兩件事:第一，「耶穌歡樂......」;第二，祂完 全順服天父的旨意。祂的喜樂是完全和不斷順服天父的喜樂，正如蓋恩夫人 (Madame Guyon) 所說:「接納神給我們的悲傷是多麼有福氣啊!」當我們從神手中接受痛苦、悲 傷以及快樂，我們的喜樂便會得到真正的滿足。

4. **藉著聖靈**。路 10:21 直譯是「耶穌被聖靈感動就歡樂」，有另一個翻譯是這樣的:「那 時耶穌被聖靈充滿就歡喜若狂」( 查閱及比較羅 15:13)。正正在這時刻，主耶穌本是一 個完全的人，在一個完全的軀體裡面，現在已經升到天上。祂盼望祂的喜樂存在我們心 裡。怎能如此呢?祂在那裡而我們在這裡?祂正在天上而我們在地上!答案是──藉著 聖靈。「聖靈所結的果子，就是......喜樂......」( 加 5:22, 比較徒 13:52 及弗 5:18)。
