**聖經給予我們以下幾個很重要的啟示：**

1. 神創造社群

2. 撒旦破壞社群

3. 主耶穌使人和好 (弗2:14)

4. 神的心意是要我們學習改善人際關係 (太7:12, 路6:31)

5. 人際關係不是技術和技巧，而是誠、愛、珍惜和尊重 (林前13)

** 甚麼東西會影響人際關係？**

1. 自我認識

2. 對別人的認識 (與人相處之道、處理分別)

3. 積極與消極的人生觀

4. 饒恕與懷恨

5. 溝通方法

6. 愛心

7. 自我中心與捨己

8. 謙和或敵視的態度

9. 自我形象與安任感

10. 偏見與客觀

11. 處理衝突和壓力

12. 誠信

13. 人與神的關係

** 建立人際關係有什麼條件？**

彼此接納 / 開放 / 互動 / 主動 / 誠信 / 成熟 / 穩重 / 安全感 / 注重個人衛生 / 可以保守秘密 / 肯定自己 / 尊重 / 幽默 / 可愛 / 像耶穌 / 有吸引力 / 大方 / 重視關係 / 溫柔 / 寬容 / 不嫉妒 / 負責任 / 忠 / 豪爽 / 聽 / 細心 / 表達力豐富 / 熱誠 / 鼓勵人 / 關係輕鬆 /. 一個好人 / 專一 / 愛 / 融洽 / 善於表達 / 不求回報，不計較利益 / 放低自己 / 謙卑 / 懂得溝通 / 懂得多國語言 / 平意近人 / 有禮貌 / 和藹可親 / 笑 / 真 / 少廢話 / 同理心 / 信任人 / 接受被愛及肯愛人 / 在真理之下彼此承擔生命 / 客觀

**破壞人際關係的行為和心態**：

自私 / 內心 / 老實直接 / 不懂欣賞人 / 裡外不一致 / 沒有真理 / 別人說話卻沒有反應 / 沒有一個健康的自我形象 / 不尊重人 / 不留心人的需要 / 過份依賴 / 太過事工型(只著重工作) / 太權威 / 不認真

**良好的溝通方法：**

主動 / 身體語言 / 別只顧自說自話 / 聆聽 / 了解對方感受 / 勇敢表達 / 投其所好 /覆述對方的意思再加以肯定 / 積極和鼓勵對 / 送禮 / 體諒別人的缺點 / 同理心（不要有身份對比）（身體語言、用語都有影響） / 盡力溝通直至互相理解（堅持） / 適當的時間、情緒溝通 / 說話要緊慎 / 尊重 / 開放自己錢包 / 不要看扁人 / 一同做傻勁的事(不要太正經) / 愛心
