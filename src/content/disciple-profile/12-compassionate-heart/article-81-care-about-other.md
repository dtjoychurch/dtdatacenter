關懷他人

**鑰節:「那裡的人，一認出是耶穌，就打發人到周圍地方去，把所有的病人，帶到祂那裡;只求 耶穌准他們摸祂的衣裳繸子，摸著的人，就都好了。」 ( 太 14:35-36)**

一個基督徒要過得勝的生活，必須經常和有計劃地尋求與不認識主耶穌的人分享祂的愛;但這要 到他對許多失喪的 ( 路 19:10)、已被定罪的 ( 約 3:18)、以及在神的震怒之下的人 ( 約 3:36) 感到 有一種真誠的關懷，一個得救的負擔，他才會開始這樣做。你對失喪的人感到有一點關懷嗎?你 熱愛靈魂嗎?當你想到你所愛的人、朋友及其他千百萬未得救的人時，你有負擔嗎?從前在我們 公司中工作的人，藉著神的幫助，要到多久我們才向他們述說我們的奇妙救主?或者我們根本漠 不關心?那些我們所愛但未悔改歸主的人和朋友能否跟我們一起說詩篇 142:4 呢?留意以下在太 14:35-36 所說的。

**一、 讓我們描述一下我們周遭許多需要深切關懷他們得救的人。**

若我們問:那些失喪的人真正的需要是甚麼?這段聖經怎樣回答呢?它告訴我們有關那時代 的人的三件事情，這三件事同樣適用於今日的人。

1. **他們是有病的** (35 節 )。
今日許多人可能是虔誠、受人尊重並過著一個道德高尚而正直的生活，但每一個未得救 的靈魂都是被罪的病所控制著，除非他們得到醫治，否則他們的前景堪虞 ( 羅 6:23)。人 類的最大需要是藉著相信主成為完全。許多人在一個患病的景況中生存、死亡，沒有神 沒有指望 ( 弗 2:12)。

2. **他們在一段距離之外** (35 節 )
「那裡的人，......打發......去......」，這表示距離。就地理上的意義上來說，他們與主 有一段距離，在那意義上他們確是這樣;就靈性上的意義來說，今日許多人也是這樣。 在很大的程度上，今日和這一代的年輕人在成長的過程中沒有任何關於神和祂恩惠福音 的知識，他們對聖經和福音的無知叫人吃驚。我們對這許多的人需要何等的關懷呢! ──查閱太 9:36。

3. **他們是殘障的** (35 節 )
他們是被帶到主面前的。的確，每一個罪人都被罪弄得殘缺不全 ( 羅 5:6)，但確實也有 很多人在體面的外衣下被虛假、酗酒、慾望、毒品、邪惡等罪弄得殘缺不全。為了這些人， 我們需要感受和表達深切的關懷。

**二、 我們何時才真正開始關懷他人的靈魂?**

35節給我們答案。是當「那裡的人，一認出是耶穌」，於是「就打發人到周圍地方去......」 我們很容易看出發生了甚麼事。這些人自己找著了耶穌，他們立刻關注其他人也能找著祂。 這是經常發生的;「認識」和「去」是並行的。當我們真的認識祂，我們便會為祂而去， 而我們認識祂的程度決定我們去的程度 ( 查閱約 14:9 及腓 3:10，及比較詩 126:6 及但 11:32)。接著，是尋找失喪者的資格和激勵，就是個別和深入地認識主 ( 查閱約 1:41, 49)。

**三、 這種關懷何時表現出來?**

若我們真的熱愛靈魂和關注他們的得救，我們應作甚麼? 35 及 36 節告訴我們「那裡的人， 一認出是耶穌」，他們便作了三件事:

1. **他們尋找** (35 節 ) 。他們到周圍地方去，尋找那些需要主耶穌基督觸摸，醫治與拯救的 人。他們為靈裡貧窮的人走遍周圍地方。這是主給我們的大使命 ( 可 16:15) 。斯塔德(C. T. Studd) 給與中非宣教士以下忠告:「將這簡單的福音傳揚出去，將它帶進你整個廣 大的區域，務必使每個靈魂得知救恩的途徑及同樣得到救恩的機會。」

2. **他們帶** (35 節 ) 。「帶」這個字是這課最重要的字眼。它表示若我們要成功為基督得人， 我們必須回到這個重點。去到他們之中固然重要，但拯救的工作不止是去到那些失喪的 人那裡這麼簡單。靈魂必須被帶到基督面前。一個漁夫不會單單滿足於釣魚;他釣到魚 時才會真正滿足──你和我也必不要單單滿足於把救主的愛告訴人;我們必須尋求祂的 恩典將他們帶到祂的面前。

3. **他們求** (36 節 )。他們求祂醫治那些他們所帶來的人──換言之，他們祈求。真正對靈 魂的熱愛很快會表現於為他們得救而作的恆切禱告中。在禱告中神會向我們顯明那些祂 想我們尋找並為祂得著的人，在禱告中我們亦會成為流通管子，讓聖靈作成祂得人的工 作。 四、這種對他人的關懷在何處開始實踐? 35 節再提供答案:它告訴我們「那裡的人......打發人到周圍地方去......」他們成為自己同胞 的福音使者!當我們熱愛靈魂，我們會開始對那些與我們同住和住在我們周圍的人的得救感 到負擔和關注。我們應「在耶路撒冷」開始 ( 徒 1:8)。
