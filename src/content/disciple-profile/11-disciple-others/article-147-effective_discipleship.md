1. 準備
@ 重溫上次守望記錄，或代禱需要。
@ 將有關資料或工具預備. .e.g. 靈修、禱告......或有關書籍。
@ 自己的心 (留下空間、位置去聆聽及關心對方需要)。

2. 禱告
@ 祈禱神作奇妙的事，超過人所想所求。
@ 求神開放人心，親自與他說話。
@ 求主賜下亮光、智慧、知識言語去建立對方。
@ 求神同在彰顯。

3. 計劃
要有優先次序："關心問候、跟進上一次定目標、現階段成長、彼此代禱、簡單功課。不要單只是完成計劃，人比程序更為重要。
可參考安排內容如下：
@ 靈程地圖
@ 對方需成長地方 e.g. 壞習慣、食煙.........等
@ 去發現值得欣賞/肯定地方。
@ 去發現進步及值得鼓勵對方，感恩事情。
@ 去發現潛在恩賜。
@ 關心個人生活層面/學業/家庭/人際關係/戀愛交友生活.... 等。
@ 教會提供必須基礎訓練。
@ 人生異象、目標、成長路向。
@ 與神關係、靈修、禱告。
@ 適切裝備訓練 (小組訓練) 等等。

4. 檢討
@ 檢討守望能否達到目標。
@ 檢討守望中自己可以改善的技巧。
e.g. 我有否缺乏聆聽與耐性？
# 我回應是否恰當？
# 有否感同身受？
# 有否肯定及鼓勵對方？欣賞對方？
# 有否足夠勇氣去挑戰對方生命成長？有否逃避問題及對質的機會？
# 我們性格是否需調節，以致可彼此相處？
# 我對對方了解是否足夠？
# 我對自己及對方有否新發現？新認知？
# 我有什麼地方可以成長？
# 在對方生命中，有什麼可學習的地方？
# 有否倚靠神的心去完成所服事工作？
# 記錄守望內容，以便日後參考及跟進。

5. 記念/默想 帖前1:2-3
@ 將對方交托給神，用禱告托著對方生命。
@ 在不斷思念默想中，讓神啟發及帶領了解對方更多及背後問題及屬靈營疊上需要，記錄下來。
@ 在禱告中更建立彼此靈裡關係。

6. 提醒
@ 「凡你們所做的都要憑愛心而做。」林前16:14
不只為責任去守望，要用愛去守望，以愛代禱，以愛聆聽，以愛交代，以愛關心，以愛挑戰，以愛跟進。愛是永不止息。
@ 守望除了『望』外，有時『手』也要伸出，行動上幫助也很重要，幫助就是服侍，服侍在最小人身上，也就是服侍主身上。
